## 使用 AI，同时保留现有技术栈

<CardGrid>
  <Card title="理解整个 Site" icon="seti:ai">
    保留多个跟随 Site 的持久 Agent Session；只在需要时显式附加文章、选区、
    编辑缓冲、预览错误或文件上下文。
  </Card>
  <Card title="执行受限修改" icon="pencil">
    Agent 通过限定在当前 Site
    的类型化工具读取、搜索、创建、编辑、移动或删除文件。
  </Card>
  <Card title="审查每项 AI 操作" icon="open-book">
    修改前逐项审批，检查本地 Git 变化，再使用网站自己的生成器和主题预览。
  </Card>
  <Card title="由人控制发布" icon="rocket">
    通过独立流程提交并发布审查后的 ChangeSet；Site Agent 没有远程或发布工具。
  </Card>
  <Card title="恢复" icon="setting">
    发布失败时安全重试或回滚；Studio 停止运行也不会影响已经上线的静态网站。
  </Card>
</CardGrid>

## 按你的目标开始

- **安装 Blog Studio：** 阅读[自行托管指南](./guides/self-hosting/)，然后[添加工作区](./configuration/workspaces/)。
- **接入 Hexo 网站：** 挂载仓库前查看 [Hexo 指南](./guides/hexo/)。
- **开始使用 AI 工作流：** 从 [Site Agent 指南](./use/agent/)了解会话、审批和文件权限。
- **发布到腾讯云：** 查看 [COS/CDN 配置与安全要求](./providers/tencent/)。
- **扩展其他工具：** 阅读[适配器架构](./adapters/overview/)和 [v1 API 参考](./reference/adapter-api/)。
