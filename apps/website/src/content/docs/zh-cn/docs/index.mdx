## 你可以完成什么

<CardGrid>
  <Card title="写作" icon="pencil">
    打开现有 Markdown，在可视化或源码模式中编辑；未知 front matter
    和生成器语法不会被丢弃。
  </Card>
  <Card title="预览" icon="open-book">
    使用网站自己的生成器和主题构建，看到更接近最终上线的效果。
  </Card>
  <Card title="AI 协助" icon="seti:ai">
    把文章、Markdown 选区或预览错误交给 Site
    Agent，并在应用修改前检查权限和内容。
  </Card>
  <Card title="发布" icon="rocket">
    先检查文件变化，再构建、上传、刷新缓存并确认线上版本。
  </Card>
  <Card title="恢复" icon="setting">
    发布失败时安全重试或回滚；Studio 停止运行也不会影响已经上线的静态网站。
  </Card>
</CardGrid>

## 按你的目标开始

- **安装 Blog Studio：** 阅读[自行托管指南](./guides/self-hosting/)，然后[添加工作区](./configuration/workspaces/)。
- **接入 Hexo 网站：** 挂载仓库前查看 [Hexo 指南](./guides/hexo/)。
- **使用 AI 协助：** 从 [Site Agent 指南](./use/agent/)了解会话、审批和文件权限。
- **发布到腾讯云：** 查看 [COS/CDN 配置与安全要求](./providers/tencent/)。
- **扩展其他工具：** 阅读[适配器架构](./adapters/overview/)和 [v1 API 参考](./reference/adapter-api/)。
