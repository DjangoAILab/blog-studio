Studio 预览会在挂载工作区内启动配置的生成器，并通过已认证的预览生命周期代理结果网站。

## 开始预览前

请确认：

- 工作区可信；
- 已按容器架构安装 lockfile 中的依赖；
- 配置的构建可执行文件位于工作区内；
- Studio UID/GID 可以写入生成输出；
- 生成器能在管理员设置的超时内完成。

适配器子进程接收白名单环境变量和参数数组，而不是浏览器提供的 shell 片段。

## 生命周期

健康的预览进程会在同一工作区复用。空闲预览会停止，显式停止会结束子进程。构建错误以诊断形式展示，不会被通用 Markdown 渲染悄然替代。

预览不是生产：它不会上传对象、让缓存失效或推进发布状态。
