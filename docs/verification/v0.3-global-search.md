# v0.3 Global Search Evidence

Date: 2026-08-07

## Delivered behavior

- The main-nav search control opens a modal search surface rather than merely
  navigating to Content.
- Input is debounced for 250 ms; search results remain body-free and reuse the
  Site content endpoint's stale-response guard.
- Escape closes the dialog and restores focus to the search trigger.
- Search covers title, path, collection, tags, and Hexo categories; category
  search has a focused API assertion.
- `contentSearch` persists in the URL and is used to initialize the app after a
  browser reload.
