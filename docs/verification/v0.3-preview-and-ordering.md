# v0.3 Preview and Content Ordering Evidence

Date: 2026-08-07

## Scope

- Markdown preview canvas allocation with and without the enhanced-preview
  fallback banner.
- Explicit publication, content-update, filesystem, working-copy, and activity
  timestamp semantics.
- Default activity-descending ordering; supported sort fields and directions;
  stable pagination and URL-restored sort choice.

## Contract checks

- A newer Hexo `date` sorts ahead of an older post even when their filesystem
  mtimes are the same or newer; mtime is returned only as
  `filesystemModifiedAt`.
- API accepts `sort` and `direction` only from the supported allowlist; it uses
  `activityAt desc` by default, puts missing values last, and uses document ID
  as the stable tie-breaker.
- The content-library controls persist non-default sort/direction to
  `contentSort` and `contentDirection` URL parameters. Search/filter/page URL
  restoration remains part of the global-search task.
