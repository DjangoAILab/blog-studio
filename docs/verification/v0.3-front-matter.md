# v0.3 Front-matter Preservation Evidence

## Scope

The first authoring increment preserves canonical Hexo front matter while a
working copy is edited, and makes the common taxonomy fields available without
forcing authors into YAML.

## Automated checks

- `CI=true corepack pnpm --filter @blog-studio/adapter-hexo test` verifies a
  title edit keeps an untouched comment, key order, quoted scalar, list/scalar
  shape, and nested YAML comment.
- `CI=true corepack pnpm --filter @blog-studio/persistence test` verifies the
  source YAML retained with a draft survives persistence and migration from a
  v0.2 database.
- `CI=true corepack pnpm --filter @blog-studio/studio test -- app.test.ts`
  passed on 2026-08-07 after this increment. One earlier release polling timeout
  was reproduced as an intermittent test-only timeout and passed on immediate
  retry; release logic is not changed by this increment.
- `CI=true corepack pnpm --filter @blog-studio/studio exec playwright test
  e2e/authoring.spec.ts` creates a native draft, sets tags and category, waits
  for autosave, reloads the browser, and asserts both values are restored.

## Current boundary

This evidence covers lossless preservation for valid source YAML and the native
taxonomy controls. The Site-defined metadata schema, advanced YAML editor, and
malformed-YAML repair path remain explicit checklist items; they are not
represented as complete by this record.
