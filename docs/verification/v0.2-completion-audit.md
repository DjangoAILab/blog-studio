## Continuing safety boundary

This acceptance authorizes the v0.2 authoring/control-plane image, not a
production content release. Any future apply, commit, Provider invocation, cache
purge or release must satisfy its own product confirmation; a production remote
release still requires a new, explicit, contemporaneous owner confirmation.

The current owner password must still be treated as exposed because it appeared
in a historical acceptance-task tool log. The owner explicitly authorized
continued use without rotation on 2026-08-06. The credential file remains
outside the repository with mode `0600`; that limits local file access but does
not remediate the historical exposure. Future rotation remains recommended, but
by the owner's explicit direction it is not a v0.2 completion gate.
