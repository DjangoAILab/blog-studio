# v0.2 Container and Operations Verification

Verified on 2026-08-06 on branch `codex/v0.2-site-foundation`.

## Default deployment contract

- Docker Compose requires only a cookie secret for core authentication. The
  v0.1 opaque auth-token secret is absent from the normal deployment path.
- The first owner password is initialized from a trusted container invocation
  before Studio starts. Interactive use hides and confirms the password;
  automation may use stdin without placing it in the process argument list.
- The compiled server keeps legacy live-tree release disabled unless the
  operator explicitly sets the temporary compatibility environment switch.
- Primary README and self-hosting documentation describe password login,
  credential status/reset, Site/ChangeSet terminology, Markdown fallback, and
  immutable committed-revision release.

## Reproducible evidence

```sh
docker compose config --quiet
CI=true corepack pnpm quick-start:smoke
```

Result: PASS. From an empty database, the smoke builds or consumes the
production image, initializes the owner through the compiled CLI, starts the
hardened Compose service, logs in with the password, verifies the public
not-registered setup state, discovers and registers the configured Site, edits
through the unified content/working-copy APIs, loads a real enhanced preview,
proves the Git tree is untouched, and keeps publishing disabled.

```sh
CI=true BLOG_STUDIO_SMOKE_IMAGE=blog-studio:quick-start \
  corepack pnpm container:smoke
```

Result: PASS. The image runs as non-root with a read-only root filesystem and
no Linux capabilities; health, password authentication, Site discovery and
registration, durable working-copy state, clean SIGTERM, and cold container
recreation passed. Before recreation the smoke seeded an interrupted preview
sandbox in the persistent data mount; the new process removed it before
becoming healthy without disturbing the Site or working copy. A third cold
start with invalid configuration preserved login/setup recovery while health
and operational Site APIs failed closed.
