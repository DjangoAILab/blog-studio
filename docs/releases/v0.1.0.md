# Blog Studio v0.1.0

Blog Studio v0.1.0 is the first self-hosted publishing workbench release for
file-based static sites. Markdown and Git remain canonical while the browser
owns durable drafts, article-scoped assets, real generator preview, and a
visible verified release pipeline.

## Highlights

- Generic versioned generator, repository, asset, publisher, and cache adapter
  boundaries, with built-in command and Hexo generator support.
- Responsive visual/source Markdown writing, optimistic revision protection,
  durable SQLite autosave, native Hexo drafts, and real preview output.
- Content-addressed article assets with protected legacy prefixes and
  preview-before-delete orphan cleanup.
- Manifest-driven filesystem and Tencent COS publishing, classic Tencent CDN
  and EdgeOne cache adapters, public release-marker verification, recovery, and
  rollback.
- Hardened non-root Docker deployment, Traefik integration, backup/restore
  tooling, dependency-free Quick Start, landing page, and documentation site.

## Deliberate scope

v0.1 is single-user and self-hosted. Multi-user collaboration, scheduled
publishing, AI writing, hosted control planes, and analytics are later product
capabilities rather than incomplete placeholders in this release.

Existing public paths are never migrated automatically. A populated deployment
must pass explicit baseline adoption before Blog Studio can publish, and legacy
resources stay outside application-managed deletion scopes.

## Install and upgrade

New installations should follow the repository Quick Start and pin the exact
container reference from `container-digest.txt`. Existing installations must
follow the attached `UPGRADE.md` (also stored at `docs/guides/upgrading.md` in
the source archive), retain their complete Compose override set, and take a
verified backup first.

Verify downloaded assets with:

```sh
sha256sum --check SHA256SUMS
```

On macOS, use `shasum -a 256 --check SHA256SUMS`.
