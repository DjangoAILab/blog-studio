# Blog Studio v0.3.0

Blog Studio v0.3.0 is the first public AI-first release after v0.1.0. The
product is a self-hosted AI content workspace: a Site Agent can read and
modify the real Markdown workspace, recognize attached photographs, and
organize a draft—while you approve tool calls, review the diff, and keep
publishing in your own hands.

Files, Git, the generator, theme, URLs, and hosting stack stay canonical.
Studio does not replace them.

## Highlights

- **Write with the whole Site.** Durable Site-scoped Sessions follow the
  workspace, not a single article. The current page is injected as turn
  context; you can keep several sessions and switch, rename, or archive them.
- **Join a selection as `#1`.** The Crepe toolbar and source-mode control share
  an AI-plus **加入对话** icon. Selected passages become removable mix tags
  inside the composer, so you can write “这一段 #1 跟这一段 #2 矛盾”.
- **See the photograph, then organize the essay.** Attach an image to the
  Session. A configured vision adapter describes it; the original file stays
  with the transcript. The Agent can then outline headings, write a caption,
  and edit the on-disk article.
- **Stay in the workbench.** The AI panel docks beside the writing paper,
  collapses the content library when space is tight, and uses the same cream
  frosted chrome as the rest of Studio.
- **Review every change.** Approval or YOLO is explicit. Tools are typed and
  Site-bounded. ChangeSet prepare / apply / local commit / remote release
  remain separate human confirmations. The Agent cannot publish.

## Demo writing task

Use this task on a fresh Session to exercise vision and organization:

1. Open a draft and drop in a still photograph—the release media includes
   `docs/media/cover-afternoon.jpg` (a sunlit desk, open book, tea, and pen).
2. Select a starter sentence and click **加入对话**. It lands in the composer
   as `#1`.
3. Attach the same photograph with **附件**.
4. Send: “识别照片里的物件和光线，把 #1 整理成带小标题的短文，并写一句图片说明。”
5. Approve the file edits, preview with the real theme, then prepare a
   ChangeSet yourself.

The README GIF and the stills in `docs/media/` walk the same path.

## Compatibility and operations

v0.3.0 includes the v0.2 workbench (owner password, Site discovery, unified
library, disk-first authoring, ChangeSets) and the Site Agent platform. A
copied v0.1 SQLite database migrates transactionally. Runtime images include
Git. The container remains non-root and read-only-root compatible.

Upgrade by pinning the immutable digest from `container-digest.txt`. See
[Upgrade and rollback](../guides/upgrading.md). Do not point a durable host at
`blog-studio:dev`.

```sh
corepack pnpm candidate:manifest
```

## Deliberate scope

v0.3.0 does not ship multi-user collaboration, scheduled publishing, or an
unattended content farm. Statistics dashboards remain out of scope. The Agent
has no remote Git, no generic shell escape, and no publish tool.
