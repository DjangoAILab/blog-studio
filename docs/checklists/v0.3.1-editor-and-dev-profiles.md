# v0.3.1 Editor and Development Profiles Release Checklist

Each check requires a focused automated test or reproducible production
observation. The canonical blog repository and its public publish target must
not be modified while verifying Studio.

## Visual editor source safety

- [x] HTML comments and commented Markdown images are represented as protected
      source blocks rather than visible prose.
- [x] Visual/source mode round-trips leave protected raw source byte-stable.
- [x] Source mode remains available for protected-block inspection and editing.
- [x] Normal images still use the authenticated Studio resource route.

## Content query interaction

- [x] Sort, direction and filters use one accessible responsive query toolbar.
- [x] `activityAt desc` remains the default; query URL and selection survive
      changes and reload.
- [x] Desktop, narrow library and mobile browser checks have no overflow or
      disconnected controls.

## Local development policy

- [x] Owner YAML can select only a named host-defined development profile.
- [x] Owner YAML rejects executable commands, args, URLs and environment values.
- [x] Profiles preserve sandbox-only execution, bounded logs and same-origin
      proxy behavior.
- [x] The Site page has a direct configuration path from the unconfigured state.
- [ ] The production Hexo profile starts, passes readiness, opens through the
      proxy, restarts and stops without touching canonical source.

## Release acceptance

- [x] Focused unit/API/browser tests, full checks, formatting and E2E pass.
- [ ] PR quality and security checks pass before merge.
- [ ] A pre-deployment backup and prior-image rollback tag exist.
- [ ] HTTPS health, owner authentication, editor rendering, query toolbar and
      local-development proxy pass in `blog-editor.internal.wj2015.com`.
