# Support

Use [GitHub Discussions](https://github.com/DjangoAILab/blog-studio/discussions)
for setup questions and adapter design. Use an issue template for reproducible
bugs or feature proposals. Include the Blog Studio version, generator and
provider types, deployment shape, relevant redacted logs, and the smallest safe
reproduction.

Never paste credentials, session cookies, private site content, or unredacted
cloud responses. Security issues belong in the private process described in
[SECURITY.md](SECURITY.md).

Blog Studio v0.x is community-supported. There is no guaranteed response time
or managed hosting service.
